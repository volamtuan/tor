# **App Name**: TorMaster Pro Dashboard

## Core Features:

- Instance Deployment: Deploy and manage Tor instances via the UI.
- Real-time Stats: Display CPU, RAM, and Tor instance stats in real-time.
- Proxy Tunnel Listing: List active proxy tunnels with their port, IP, country, ping, and speed.
- Instance Actions: Enable actions to start, stop, restart, and delete Tor instances directly from the UI.
- Force Cleanup: Add a force cleanup button to stop all instances and clear data.
- Export IP:PORT: Create the function of export IP:PORT as a service

## Style Guidelines:

- Primary color: Indigo (#6366F1) for a professional and techy feel.
- Background color: Dark gray (#0B0F1A) for a modern dark theme.
- Accent color: Emerald green (#10B981) to highlight active and healthy elements.
- Body and headline font: 'Inter' for a modern and readable UI.
- Use Font Awesome icons for actions and status indicators.
- Divide the UI into distinct sections for instance management, quick tools, and active proxies.
- Subtle transitions and animations on button hovers and table updates.
